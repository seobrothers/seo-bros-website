One visible change on Friday, and a change in how every change after it reaches you.

## For our partners

The top of the dashboard now reads Active clients, Prospects and Team members, and the section below no longer repeats the client counts, so the two halves of the page describe the same book.

The Prospects card is a link. It opens the clients list already filtered to prospects, and the clients list now reads that filter from the address, so a filtered view can be bookmarked or passed to a teammate.

## Behind the scenes

From today every change to the platform is reviewed and checked automatically before it ships. Database changes travel with the code that needs them, and each one is rehearsed against a copy of the database before it reaches the real one. It sounds like housekeeping. It is what lets a small team ship in parallel without stepping on each other.
