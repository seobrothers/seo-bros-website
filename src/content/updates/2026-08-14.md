A quiet Friday with one visible change, and a change in how every change after it reaches you.

## For our partners

The dashboard used to show a Clients count at the top and then split Active and Prospects below it, so the numbers never lined up. That is gone. The top of the dashboard now reads Active clients, Prospects and Team members, and the section below no longer repeats the client counts.

The Prospects card is a link. It opens the clients list already filtered to prospects, and the clients list now reads that filter from the address, so a filtered view can be bookmarked or passed to a teammate.

## Behind the scenes

From today every change to the platform goes through a reviewed pull request with automated checks before it ships. Database changes ride along with the code that needs them and apply on merge, with a preview database spun up for each change so we see the schema apply before production does. It sounds like housekeeping. It is the thing that lets a small team ship thirty changes a day without stepping on each other, which is what the next two weeks look like.
