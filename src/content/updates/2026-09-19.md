A Saturday on the agent system: how specialist agents pick up work, and what happens when one gets stuck.

## For our partners

The client portal domain field refuses www and the bare domain and says why. Pointing either at the portal would take the client's website offline, and nothing on the screen said so until a partner nearly did it. On Asks & Approvals, answered questions read as one row each and withdrawn ones fold into a collapsed group instead of filling the page.

## Behind the scenes

A specialist agent is now a scheduled row that says, on the row, which tasks it may claim: kind, lane, status, approval state, due. The tick claims the task before the run starts and the run is fenced to it, so nothing about which task is left to the agent and nothing about which agent is left to code. Seven specialists replaced three catch-all pickup agents that ran one recipe for every task kind. The conditions are named presets, describe the situation and hold the logic in one place, so a wrong option is fixed once for every agent using it. One visible effect: approved content publishes on the specialist's next scheduled pass rather than at the moment of approval. Agents also gained a kind meant for people, Process, Specialist or Feedback, with how each wakes shown beside it.

A guest post writer withheld an article because it read a rule naming six on-site surfaces as covering a link on another site, and nobody could tell it otherwise: the alert carried a bare run id and the chat opened read-only. The escalation now links straight into the run, a staff member replies in correction mode, their word outranks every rule and note the agent holds, and the agent fixes its notebook and finishes the job. A writer that declines never blocks the placement; it waits on the escalation. Every rules block now opens with the reading rule: a rule covers the surfaces it names and nothing else.

Tasks our team writes by hand are now read against the task standards before they are saved, the same two documents agents read on every run. We calibrated four judges on twelve known tasks and kept the one that read all twelve right.
