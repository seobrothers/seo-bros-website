A Friday with one decision for partners and a long stretch of plugin work underneath.

## For our partners

Connecting a client's website no longer means the agent starts applying changes there. Site edits and content publishing route to a person by default, connection or not. A new Connected sites card on Settings > Implementation, and a Connected site card on each client's implementation page, turns automatic implementation on for the workspace or for one client. Changing who implements resets automation to manual, and the page tells you when that happened.

Plans that empty out now end cleanly through every door: cancelling the last item from the task list, the planning page or the API ends the plan and withdraws its approval request. A plan's approval request can only be opened while the plan is still proposed, so an approved plan never shows as awaiting a decision again.

Over the API, loose tasks are site edits or citation orders, and plans are content, links or Business Profile posts. Citation orders are validated at the door the same way the agent's are.

## Behind the scenes

The WordPress connector went from 1.8.2 to 2.0.3 in one day, each release built on something a live site taught us. Edits now carry an administrator's HTML permissions, so a page builder's sanitizer no longer strips a map embed or accessibility attributes when one sentence changes. Responses carry no-cache headers, so a host's page cache cannot hand back a pre-edit page. Elementor edits rebuild only the edited page's stylesheet, so a text edit never leaves the rest of a site waiting on its CSS.

Then 2.0.0: pages whose copy lives in custom fields are readable and editable, site-wide text search and scans, link placement that knows a copy link from a navigation link, a page outline, inserting a section next to a named one styled like its neighbour, removing a named block, adding menu items. The agent's website tools no longer close tasks on their own; they record what they did and the agent decides. Sixty-six bench checks across five page builders before release, and three more point releases by evening from the first live site.
