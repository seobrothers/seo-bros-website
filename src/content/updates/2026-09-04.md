A Friday with one decision for partners and a long stretch of plugin work underneath.

## For our partners

1. Connecting a client's website no longer means the agent starts applying changes there. Site edits and content publishing route to a person by default, connection or not, and you turn automatic implementation on for the workspace or for one client.
2. Plans that empty out now end cleanly however the last item goes: cancelling it from the task list, the planning page or the API ends the plan and withdraws its approval request. A plan's approval request can only be opened while the plan is still proposed, so an approved plan never shows as awaiting a decision again.
3. Through the API, one-off tasks are site edits or citation orders, and plans are content, links or Business Profile posts. Citation orders are checked on the way in the same way the agent's are.

### 1. Turning automation on

The switch is a new Connected sites card on Settings > Implementation, and a Connected site card on each client's implementation page. Changing who implements resets automation to manual, and the page tells you when that happened.

## Behind the scenes

Each WordPress connector release today was built on something a live site taught us. Edits are saved with an administrator's permissions, so a page builder no longer strips a map embed or accessibility details when one sentence changes. Every response tells the host not to keep a copy, so a site's cached copy cannot hand back the page as it was before the edit. Elementor edits rebuild only the edited page's styling, so a text edit never leaves the rest of the site waiting.

The 2.0.0 release: pages whose copy lives in custom fields are readable and editable, site-wide text search and scans, link placement that knows a copy link from a navigation link, a page outline, inserting a section next to a named one styled like its neighbour, removing a named block, adding menu items. The agent's website tools no longer close tasks on their own; they record what they did and the agent decides. Bench-checked across five page builders before release, then refined against the first live site.
