A multi-location client with thirty-odd studios and 132 posts stacked on the last two days of the month is what set the day's agenda.

## For our partners

Every Business Profile post now carries the location it was written for and publishes to that profile, never to whichever profile happened to be first on the campaign. Due dates within a month spread evenly across it instead of piling up at the end. Planning pages show a Location column on multi-location clients, and the post sheet names it. Posts imported from the old system, which had been assigned to nobody who could publish them, move onto the same publisher.

Approval rules for website edits split in two: Visible page changes, which default to requiring your approval, and Technical changes, which default to automatic. Safe mode still requires everything. Any override you had set carries onto both.

A content task in its publish leg now reads Publishing: Service page (or Blog post, Geo page) in your task lists, with a View the approved content button and Mark as published on the task itself. New pages planned from now on need a target URL up front, so the publisher is never guessing where a piece goes.

## Behind the scenes

Guest post topics and articles are written by invoked agents now, the same door the content writers use. Higher-authority link placements, which had been hand-sourced, run through the same workflow drawing from any site that qualifies on authority alone, with hand-sourcing as the fallback when none does.

Our team's task queue reorders by urgency: overdue first, then due date, undated last. Tasks beyond the two-week work-ahead window wait on their own Upcoming page and join the queue on their unlock day. Blocked tasks sit in their own section, a task with an approval outstanding cannot be picked up, a team roster shows who holds what, and the filters live in the address bar so a filtered queue is a link.

Link, Business Profile post and content page tasks can only be born inside plans. Loose ones had been created with no links, no month and no plan, invisible on planning pages. A delivered discovery's website and local analysis can be refreshed in place with the campaign's current competitors and Business Profile, instead of marking it lost and resubmitting.
