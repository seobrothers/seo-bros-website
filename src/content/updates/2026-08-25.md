Task lanes landed, and the admin side got its first fleet-wide views.

## For our partners

Website edit tasks now carry a lane. A technical edit can cover up to five pages at once and never has to wait behind another edit on the same page. An on-page edit is one page of visible content, and it holds that page briefly so two content changes never collide. The New task form asks which; the agent and our team say which when they file one. Business Profile edit is a task type of its own, labelled that way in your task list and approvals.

Work our team is still reviewing before it reaches you stays out of sight until we release it. The approvals queue, the sidebar badge and the client portal show it once, when it is released, and you are notified once, then.

For migrated partners, discoveries brought over from the old system now carry their proposal options, so marking one won carries the agreed option into the campaign like a native discovery.

## Behind the scenes

Admins have an Operations section. Campaign Onboarding lists every campaign whose setup checklist is not finished, across every partner, filtered by phase, with the actual checklist items in a popover and a click into the workspace. Campaign Fulfillment shows one month at a time, one row per campaign, one column per delivery stream, each cell reading planned, done and scoped; gaps only by default. The checklist is built once and shared by the client portal, campaign details and this page, so the three can never disagree.

Agents gained a view of a crawl's noindexed pages, with sitemap contradictions first and a note that a noindex is normally deliberate. The auditor stopped scoring noindex as a critical issue at the same time. Staff who follow a deep link into a client's workspace get a confirm-and-enter page instead of a bounce, and a page audit now evaluates only the page that changed.
