A Sunday. Nothing moved on partner screens; the work was all underneath.

## For our partners

Nothing moved on the surface today; the work was all underneath.

## Behind the scenes

Connector 2.2.0 and 2.3.0 were built inside real on-page tasks, one limitation at a time. Link insertion takes a context phrase, so when an anchor repeats on a page the agent names the sentence instead of widening the anchor. The page outline reports children counts, device visibility and background images, and every element carries an id, so a block can be cloned with its design, a heading's level changed with its look pinned, and a top-level section moved, on Elementor, the block editor, classic pages, Divi and WPBakery. Thirty-four bench checks before release.

The connector install script hardened after a sweep across the book: hosting challenge pages that clear themselves in a browser, admin email interstitials, custom two-factor screens, passwordless login toggles, maintenance mode after an upload, and a guard that refuses to install when the login on file names a different host than the client's site (a staging copy). Installs now happen case by case as tasks need them.

The staff task queue no longer lists tasks with a pending approval request, in the open queue or on Upcoming; they could not be picked up anyway and were inflating the overdue count. Pending Approvals is where those get chased, and its plan rows now show how many pieces each plan carries.
