This is the week the record shows real agencies on the platform. By Monday the first legacy partners had been moved over from Workbench, and the migration scripts spent the week being corrected against their data. Around them, the agent editor was rebuilt for the people who would now run it daily, and the task queue got the filters a full book demands.

## For our partners

A weekly digest lands every Monday morning: a snapshot of everything waiting on you, pending approvals and team tasks due within the week, one deep-linked line each, sent even when the answer is all clear. It is on by default and each person can turn it off. Notification channels are per person now, off, email, in-app or both, from an Account page with Profile and Notifications tabs.

Alerts got plainer. Keyword ranking alerts wait and see before speaking: a keyword that disappears is confirmed missing after three days, the same for every keyword, and day-to-day movement is reporting, not alerts. Monitoring emails say where the change happened and link to the exact alert. Content-changed alerts fire only when there is a reviewable diff. Misspelling alerts show the correction and the surrounding context for each word. Weekly checks run on assigned weekdays rather than all at once.

Task lists show "In revisions" after a send-back instead of "Waiting on approval". Discovery reports carry real Google positions for their keywords and real dofollow referring domains. For agencies we manage under our own brand, the agent is invisible: copy reads as your team, our people appear as one team and never by name, and monitoring and Business Profile notifications stay quiet.

## Behind the scenes

The migration scripts learned the shape of the real book: healthy in-platform connections win over old tokens, the newest active agreement wins per campaign, soft-deleted tasks are never resurrected, placeholder tasks stay out, and open link tasks for the current and future months land agent-assigned with a spread due day. A teardown script removes a platform-created partner cleanly, and the runbook gained the chapter that ends the overlap period.

The agent editor became a working surface: auto-save per change, ordered pickers for the documents an agent reads, one compact row per data set, plain condition labels with tooltips. The agent page shows a roster of active agents and a table of work sessions. The campaign review itself is now a plain scheduled agent row, no different from any other. Schedules never backfill: occurrences before an agent was armed lapse, so enabling something old does not fire a month of catch-up. Client comments became agent territory, with a trigger and a data set the builder can wire.

Events collect. When a partner removes three plan items and then sends feedback, the agent gets one run with all four payloads rather than four runs. A run that dies mid-work resumes as the same session, knowing what it already did, because a fresh retry would double-act. Briefs became a tool the agent writes and reads. Two new tools arrived: everything one page ranks for, and anchor text profiles drawn from the search results a link plan targets. Google Business posts are written by the agent, with the workflow assembling the plan. Who publishes a piece of content is derived, from the site connection first and the implementation setting second, never a switch. Our support inbox shows the client's campaign beside the thread and can hand an email to the client's agent with a staff steer.
