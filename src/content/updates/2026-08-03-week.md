The week real agencies arrived on the platform. Around them, the agent editor was rebuilt for the people who would now run it daily, and the task queue got the filters a full book demands.

## For our partners

1. A weekly digest lands every Monday morning: a snapshot of everything waiting on you, pending approvals and team tasks due within the week, one line each linking straight to the item, sent even when the answer is all clear. It is on by default and each person can turn it off.
2. Keyword ranking alerts wait and see before speaking: a keyword that disappears is confirmed missing after three days, the same for every keyword, and day-to-day movement is reporting, not alerts.
3. Notification channels are per person now, off, email, in-app or both, from an Account page with Profile and Notifications tabs.
4. Alerts got plainer. Monitoring emails say where the change happened and link to the exact alert, content-changed alerts appear only when there is a change you can read, and misspelling alerts show the correction and the surrounding context for each word.
5. Weekly checks run on assigned weekdays rather than all at once.
6. Task lists show "In revisions" after a send-back instead of "Waiting on approval".
7. Discovery reports carry real Google positions for their keywords and real dofollow referring domains.

## Behind the scenes

1. The agent editor became a working surface: every change saves itself, the documents an agent reads are picked in order, each set of data it is handed is one compact row, and what starts it is labelled in plain words with a tooltip. The agent page shows a roster of active agents and a table of their work.
2. Changes collect. When a partner removes three plan items and then sends feedback, the agent sits down once with all four rather than four times, and an agent interrupted mid-work picks up where it left off, knowing what it already did, so nothing is done twice.
3. Switching an agent on never replays the past: anything it would have done before it was switched on is skipped, so enabling something old does not set off a month of catch-up.
4. The campaign review itself is now a plain scheduled agent, no different from any other, and a client comment can start an agent too.
5. The scripts that move our book of agencies onto the platform learned the shape of a real book, a matching script removes a partner the platform created cleanly, and the written procedure gained its last chapter.
6. Briefs became something the agent writes and reads, and two new tools arrived: everything one page ranks for, and anchor text profiles drawn from the search results a link plan targets.
7. Google Business posts are written by the agent, and the plan is assembled from them.
8. Who publishes a piece of content follows from the site connection first and the implementation setting second; there is no separate switch.
9. Our support inbox shows the client's campaign beside the thread and can hand an email to the client's agent with a staff steer.

### 5. Moving the book

A connection already made on the platform wins over an older one, the newest active agreement wins per campaign, deleted tasks are never resurrected, placeholder tasks stay out, and open link tasks for the current and future months land with the agent, each with its own due day.
