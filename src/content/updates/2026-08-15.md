A Saturday spent on the discovery report, prompted by one prospect's site that did two things most sites do not: it had a twenty-thousand-page catalog, and it blocked every automated visitor.

## For our partners

A discovery on a very large site used to stop after about two and a half hours with a message that the website analysis did not finish in time, while the crawl underneath it was still running and finished fine a few hours later. The discovery now waits as long as the crawl can possibly take, about half a day at the outside, so a big catalog site gets a complete report instead of a failed one.

Some hosts refuse every automated fetch we have. On those sites the report used to say the robots file and sitemap were missing, when the truth was we were never allowed to look. Checks we could not verify (robots, sitemap, redirect consistency, soft 404s) now show as an unchecked row with a muted dash instead of a failure, so a prospect is not told a file is missing when it is sitting right there.

## Behind the scenes

When an agent links a campaign to Analytics or Search Console through one of our shared accounts, it now only sees properties whose website matches the campaign, and it can only link what it was shown. Same outcome as before on a clean match; far less noise in the agent's view on an account that holds hundreds of properties.
