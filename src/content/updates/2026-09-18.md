Friday brought one reporting change and the same product on both of our brands.

## For our partners

Conversions in the Website section of the report have always been the property's key events. Many partners never set those up, or have them tuned for Ads. The report settings sheet now has a Counted as conversions picker listing the events the linked property recorded over the last 90 days, busiest first, marked where they are already key events. Pick one or more and every conversion number in the report, the KPI, the daily chart and the By type list, uses that set in the partner view, the client portal, the CRM tab and the PDF. Nothing picked means key events, exactly as before.

Partners on both of our house brands now see the same product. Tasks are read on the partner side and shaped by the team; monitoring checks, content generation and campaign scope are set by the team. Each client's Contacts tab has a switch to pause all emails to that client, and Quick actions in the top bar pauses or resumes every client at once. Every discovery now gets an agent's draft followed by a strategist's review before you are told it is ready.

## Behind the scenes

Agents were briefly able to write facts. Alongside real ones, a second brand, the company's history, came logs of what the agent had checked that run. An agent that must look at the site every wake will always find something to write down, so the tool came out. Facts are written by people; agents read them and keep their notebooks.

A run woken for one draft had read all four of the month's drafts, regenerated three, and left the sibling runs arguing with locks. An event run about one task now touches that task only.

Page reads got more literal. A 404 is the site's own answer and counts as having read the page. Redirects are named hop by hop with their status, and a redirecting link is repointed rather than called dead. Domain monitoring stopped counting down to registration and certificate expiry, which flagged every live site once a year, and watches for a registration actually lapsing. Link placements survive a paused writer agent, and transient failures retry on the next sweep.
