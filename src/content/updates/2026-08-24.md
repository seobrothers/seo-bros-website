Monday was a reporting day, with a run of campaign-details follow-ups alongside.

## For our partners

1. The client report can now be viewed and downloaded for a calendar quarter as well as a month.
2. The report has a Work Delivered section: the content pieces and link placements completed in the period, each linking to its live URL where we hold the publish receipt.
3. Competitive gap reviews now live where the rest of monitoring does, and the standalone page is retired.
4. On campaign details, a Define campaign profile step joins the checklist, with a Detect from website button that classifies the client for you, and any phase tab offers a Move to this phase button that asks before it moves.
5. Content pieces cleared by your trust settings without a review now read Approved instead of Draft. Submit for approval hides on approved and pending pieces and returns as Resubmit only when a newer version has been saved.
6. Page monitoring gains an alert for a monitored page whose page size balloons between audits, critical when it nears the size at which Google stops indexing.

### 1. Quarterly reports

The period picker has a Months and Quarters toggle with a year stepper; only finished quarters are offered. Comparisons follow the period: quarter over quarter and against the same quarter last year, keyword movement from the start of the quarter to its end. It works everywhere the report appears, including the client portal, the public share link and the PDF. Scheduled monthly sends are unchanged.

### 2. Work Delivered

On by default, it can be hidden in the report settings, and drops out on its own when a period had neither.

### 3. Competitive gap reviews

Settings and a Run review now button sit on the Monitoring page, results under a Competitive Gap tab on Audits. New reviews no longer include the AI visibility comparison, since the monthly AI visibility snapshot already measures the client against competitors across all four assistants.

## Behind the scenes

1. Long agent sessions on big campaigns now run to completion however large the campaign.
2. Agents can start when a crawl completes, and only when the crawl's numbers warrant it.
3. Agents arrive with the keyword map and their own open tasks already in front of them.
4. When someone on the team starts an agent by hand, it records who.
