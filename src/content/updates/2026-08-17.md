The busiest day since launch, and most of it about the first hour after a client goes active.

## For our partners

Activation now turns on monitoring. The standard set (site health, technical, domain health, content changes, page speed, Business Profile, brand search, backlink authority, keyword rankings) switches on with the campaign, with the first runs inside the hour. Competitive gap reviews stay a deliberate opt-in. A check whose prerequisite is missing, like the Business Profile check on a campaign with no location yet, waits quietly and can be turned on from the Monitoring page once it applies.

Citation scans start at activation too, one per location on the campaign. That used to be a decision the agent made during its strategy work; it is a routine job, so it now just happens.

Assigning your team to a client has its own Team tab under the client's configuration, next to Client Portal, so the two people surfaces sit together: your side and theirs. And the Work sessions list now shows each agent session once, so a session in progress no longer appears twice.

## Behind the scenes

The onboarding agent started to take shape. It now wakes with the state of every onboarding objective already in front of it (tracked keywords, keyword mapping coverage, which plans are approved or waiting, citation scans per location, open alerts by severity) instead of spending its first several calls working that out. Its list of objectives matches the playbook exactly: alert triage is in, and citation setup is out because it is no longer the agent's job.

Switching an agent on never replays history. Alerts that were already open before the agent was enabled are not treated as new work the minute it turns on.

Each campaign in onboarding gets a thread in the team's chat, and the agent can nudge the team once a day about inputs only a person can supply (goal, brief, connections), in a header and bullets rather than prose.

Migrated campaigns arrive mid-flight, so when staff enable the agent on one, they choose which phase it starts in.
