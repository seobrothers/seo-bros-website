A Thursday split between the Sessions and Keywords pages and a long pass on how agents read a website.

## For our partners

Every row on the Scheduled sessions card now says what it runs on for this campaign ("Monthly on the 15th", "Every other Tuesday", "On request") and when it runs next, in your clock. Sessions can now run every other week, quarterly, twice yearly and yearly.

Reports gain two more switches under Website and Business Profile, after a partner reviewing yesterday's cut sent a screenshot: hide the six-month trend chart itself, or hide only the dashed year-prior line on it.

On the Keywords page, a rank cell names its state instead of collapsing everything into Not in top 100: checked with a date, stale (as of a date), awaiting first check, tracking not started, tracking paused. Tasks our side cancelled as triage no longer appear in your task list or activity; a cancel made by your own team still does.

The WordPress Plugin tab gains a share link that always serves your current branded build, and the plugin now updates from a neutral service address that carries no agency's name.

## Behind the scenes

Our site-wide optimization agent had been recommending caching and hosting work built on a number that was not server time. The crawler's response time was the whole fetch: on rendered pages, the time to the document loading. The crawler now records time to first byte only when it reached the origin directly, the speed check reads it in tiers, and it no longer weighs on the technical score. The campaign context now carries what a connected site actually runs: WordPress and PHP versions, theme, SEO plugin, cache layers.

Agents also read pages properly now. The fetch tool's default is an outline: heading tree, every link with its anchor and landmark, images with alt, canonical, robots, schema types. And an agent cannot create a task naming a page it has not opened live in that session; a planning run had ordered links from two posts that already carried them, off a stale crawl. Search Console auto-linking picks the property that covers exactly the campaign's site, so franchise campaigns on a shared domain no longer land on a sibling's property.
