A Sunday spent on one website builder and on the review page.

## For our partners

While Show changes is on, the approve and request-changes controls and the notes box step aside, so a note is always written against the draft itself and never against a blend of two versions. Hide changes brings them back. The thread stays readable throughout.

## Behind the scenes

Divi 5 stores a page's copy inside block attributes with the HTML escaped, and our WordPress connector was treating those pages as the older shortcode-era Divi. A read came back with no readable text, and an edit would have written raw markup into the block data. A member of the team found it while working a client's site edits by hand.

The connector now recognises Divi 5 as its own builder, decodes the copy for reading, and writes edits back through WordPress's own block serializer so the page is stored exactly as Divi stores it. A module that carries the same text for desktop and phone counts as one match and the edit lands in both places. Bench-tested on a copy of a live page: the round trip is byte-identical and an inserted link renders in the theme's own styling. Structure edits on Divi 5 pages are refused for now rather than attempted.

While testing we also fixed one thing for every builder: a find and replace that is refused no longer overwrites the undo snapshot, so a revert still undoes the last edit that actually landed.
