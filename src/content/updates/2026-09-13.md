A Sunday spent on one website builder and on the review page.

## For our partners

While Show changes is on, the approve and request-changes controls and the notes box step aside, so a note is always written against the draft itself and never against a blend of two versions. Hide changes brings them back. The thread stays readable throughout.

## Behind the scenes

The connector now recognises Divi 5 as its own builder, decodes the copy for reading, and writes edits back the way WordPress itself does, so the page is stored exactly as Divi stores it. Divi 5 stores a page's copy in a new way, and the connector had been treating those pages as the older Divi. A read came back with no readable text, and an edit would have written code into the page where words should be. A member of the team found it while working a client's site edits by hand.

A module that carries the same text for desktop and phone counts as one match and the edit lands in both places. Bench-tested on a copy of a live page: a page read and written back comes out identical, and an inserted link appears in the theme's own styling. Structure edits on Divi 5 pages are refused for now.

While testing we also fixed one thing for every builder: a find and replace that is refused no longer overwrites the saved undo point, so a revert still undoes the last edit that actually landed.
